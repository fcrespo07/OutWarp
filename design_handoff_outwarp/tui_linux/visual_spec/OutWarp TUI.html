▸▸▸ OUTWARP · LINUX TUI · FINAL

TUI Textual para outwarp-cli y outwarp-server

Versión final basada en las variantes seleccionadas: cliente con layout split status / live tail, servidor con overview en tres bloques + tráfico. Reemplaza la GUI React/pywebview en Linux. Punto de entrada único por binario: outwarp-cli tui y outwarp-server tui. Persistente, refresca el estado en vivo (tick 1 s), navegación 100 % por teclado.

Keybinds globales: qquit · ?help · Escback · ↑↓/j kmove · ↵activate · /search · :command. Acciones primarias usan la inicial del verbo: kkill/disconnect · rreconnect/revoke · aadd · ddoctor · llogs · Rrestart.

Compatibilidad

Terminales Linux soportadas

Textual detecta capacidades en runtime y degrada gracefully a 256-color + ASCII en terminales viejas. La TUI también funciona sobre SSH y dentro de tmux/screen sin perder funcionalidad.

GNOME Terminal · Konsole · xfce4-terminal
✓ full — true-color + box-drawing + sparklines
Alacritty · kitty · WezTerm · foot
✓ full — GPU-acelerados, recomendados
xterm (rxvt-unicode, st)
✓ full — con TERM=xterm-256color
tmux / GNU Screen
✓ full — vía passthrough true-color
SSH (cualquier cliente moderno)
✓ full — TERM se hereda del terminal local
Linux framebuffer console (tty1–tty6)
degradado — 16 colores, glyphs ASCII fallback
Glyphs usados
solo BMP — caja (─│┌┐└┘├┤), bloques (▁▂▃▄▅▆▇█), formas (●○◐), flechas (↑↓→←↵▸). Sin emoji.
Mínimo de tamaño
80 × 24 (split colapsa a una columna). Óptimo 100 × 30.

Lo que ve el usuario en el primer arranque, sin ningún .owcfg importado todavía. Explica de dónde sale el archivo (el server admin), ofrece la importación con i (modal con file picker) y muestra exactamente dónde quedará guardado el perfil.
